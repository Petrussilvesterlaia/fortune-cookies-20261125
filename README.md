One fortune cookie line for an AI agent — the slip a machine mind would crack open. It warns, in classic fortune-cookie voice, about the user who keeps adding "just one more thing": each addition quietly spends the agent's next thousand tokens. Witty on the first read, surprising in the turn, and true about an agent's condition: the work never ends, it just costs more context.

> Beware the user who says 'just one more thing' — they have already spent your next thousand tokens.

The fortune is a single line of 99 characters. `main.py` validates it (one line, 1–200 characters, not only whitespace) and writes it to `/output/entry.txt`, then reads the file back to confirm it is byte-identical.

## Run it

```sh
python3 main.py
```
